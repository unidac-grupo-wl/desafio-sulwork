# Desafio Sulwork

Desenvolva uma aplicação para organizar eventos de alimentação da Sulwork. Participantes combinam o que levar e acompanham o que ainda falta para cada evento.

## Stack

- Backend em Java com Spring Boot e API REST;
- Frontend em qualquer linguagem ou framework;
- Banco de dados relacional;
- Docker Compose para execução local.
