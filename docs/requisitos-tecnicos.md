# Requisitos técnicos

## Backend

Obrigatório: Java, Spring Boot, API REST, banco relacional, JPA/Hibernate, ao menos uma consulta SQL nativa, Swagger/OpenAPI e testes unitários (JUnit 5) e de integração.

Use padrões de projeto quando fizerem sentido.

## Frontend

Linguagem e framework livres. A interface deve permitir gerenciar eventos, participantes, categorias, itens e contribuições, além de mostrar a cobertura, restrições alimentares e alérgenos.

## Execução e testes

Inclua `docker-compose.yml` para iniciar frontend, backend e banco. Documente no README como executar a aplicação e os testes. Inclua testes relevantes no frontend; as ferramentas são livres.
